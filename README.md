# Freezer

Native C# WinForms gaming utility. The current release line is **Windows only**; Linux and macOS are not supported or shipped yet.

## Downloads

- Windows download page: [freezer-boost-hub.base44.app](https://freezer-boost-hub.base44.app)
- Latest GitHub release: [Releases](https://github.com/wannabe494639-beep/Zayno/releases/latest)

Each release includes a standalone Windows executable and a source ZIP. The current source archive is stored under `source/`. Read `RELEASES.md` inside the source ZIP for the version/tag workflow.

## Current version: 2.42.0

Active reversible optimization cards now offer a per-tweak **Rückgängig / Undo** action that restores the saved original values. The existing full restore page remains available. See `CHANGELOG.md` in the source archive for release details.

The GitHub Actions workflow builds and publishes Windows releases when a matching `vX.Y.Z` tag is pushed. Linux and macOS releases will be added only after a native port and platform builds are verified.
